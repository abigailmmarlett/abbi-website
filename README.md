# Abbi Website - Professional Portfolio

A professional portfolio website showcasing work experience, education, and certifications.

## Features

- **Work Experience Section**: Displays professional work history with detailed responsibilities
- **Education & Certifications Section**: Shows educational background and professional certifications
- Modern, responsive design that works on all devices
- Clean and professional styling with a gradient header

## Viewing the Website

Simply open `index.html` in your web browser, or use a local web server:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
